# 작업 상태와 남은 확인 사항

이 저장소는 Team Project #2의 C 구현과 재현 가능한 테스트를 공유하는 작업본이다.

- 2026-10-06 사용자 전달: 교수님이 소스 파일을 합쳐 제출하도록 안내했다. `single_file/controller.c`와 `controller.h`에 제품 구현 전체와 선언을 통합했다. 파일 수와 배치를 조정했으며 FSM/모듈별 함수 동작은 유지한다. 기본 실행에 필요한 파일은 이 두 개다.

- 통합 후 공개 헤더를 외부 함수 7개와 관련 타입으로 정리했다. 내부 모듈·모의 장치 선언은 C 파일, 직접 모듈 검사에 필요한 선언은 생성된 시험 지원 헤더에 둔다. 미사용 오류 이름과 읽지 않는 센서 유효성 필드 3개를 제거했다. [정리 결정](ADR-001-header-cleanup.md)과 [검증 기록](../single_file/VERIFICATION.md)을 참고한다.

- 제품·모의 장치는 C17이고 GoogleTest 실행기는 C++17이다.
- 주요 Structured Chart 호출 관계를 코드와 문서에 대응시켰다. 초기화/API/전방 입력 캐시 경로도 함께 읽어야 한다.
- 기존 팀 PPT에는 Controller와 회전·후진 동작 모듈 사이에 타이머 책임 설명이 충돌한다. 현재 코드는 Controller만 경과 Tick을 관리한다. 최종 설계 문서에 같은 선택을 반영해야 한다.
- 먼지 강화는 감지 중에만 유지하는 현재 팀 설계를 구현했다. 강의의 유지 시간 표현과의 해석은 최종 확인이 남아 있다.
- CLI의 출력 저장 실패 확인과 Ctrl+C 종료 처리는 추가 보완이 남아 있다. 이번 선언·상태 정리는 그 동작을 변경하지 않았다.
- 최종 제출에는 SA 기반 SD Structured Chart와 시스템 시험 보고서를 담은 PPT/PDF, 필요한 C 소스·헤더가 필요하다. 이 저장소만으로 최종 제출물이 완성된 것은 아니다.
- 전체 GoogleTest 수에는 하위 모듈 검사도 포함된다. 시스템 시험 보고서는 입력 이력·기대 상태/Command·실제 결과·판정을 시나리오별로 구분해 작성해야 한다.

실제 하드웨어, 병렬 ISR, 모든 입력 이력, 운영체제의 실시간 정확도는 이 모의 시험의 검증 범위 밖이다.
