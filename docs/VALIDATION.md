# 공유본 검증 기록

2026-10-04에 기존 빌드 산출물이 없는 공유용 폴더에서 `build.ps1`을 실행했다.

| 항목 | 결과 |
|---|---|
| 환경 | Windows, MSYS2 UCRT64, GCC/G++ 16.1.0, CMake/Ninja |
| 제품 | C17 소스 컴파일·링크 성공 |
| 테스트 실행기 | C++17 + GoogleTest 1.15.2 빌드 성공 |
| GoogleTest | 134개 실행, 실패·오류 0개 |
| 기본 시나리오 | `scenarios/demo.csv` 실행 성공 |
| 출력 예시 | `examples/demo_output.csv`와 새 실행 결과가 행별로 일치 |
| 공유 범위 | 소스·테스트·문서·고정 버전 테스트 의존성 포함, 빌드 결과·강의 원본·리뷰 백업 제외 |

CTest에 등록된 실행기는 1개이고 그 안에서 GoogleTest 사례 134개가 실행된다. 이 수치는 모듈 검사와 제어 동작 검사의 합이며, 134개의 별도 시스템 시나리오를 뜻하지 않는다.

긴 Windows 작업 경로에 대한 CMake 경고가 있었으나 빌드와 테스트는 완료됐다. 다른 PC에서는 짧은 경로에 clone하는 편이 편리하다. 다른 운영체제와 실제 하드웨어는 이번 실행에서 확인하지 않았다.

새 실행의 원시 로그와 XML은 `results/`에 생성되며 저장소에 commit하지 않는다. 사용자는 README의 명령으로 직접 같은 검사를 재실행할 수 있다. 최종 시스템 시험 보고서와 PPT/PDF 작성은 [작업 상태](STATUS.md)에 남아 있다.
